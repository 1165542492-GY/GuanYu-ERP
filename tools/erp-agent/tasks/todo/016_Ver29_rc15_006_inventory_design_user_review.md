## 三、用户确认步骤

### 步骤 1：库存类型范围

确认启用哪些 StockType（7 类全开 / 精简 / 自定义），是否包含：

- [ ] 原材料
- [ ] 外购配件
- [ ] 标准件
- [ ] 成品设备
- [ ] 维修备件（单独 or 合并配件）
- [ ] 低值易耗品
- [ ] 其他
- [ ] 是否需要「半成品」

### 步骤 2：汇总与合并规则

- [ ] 同名不同 ID：不合并（设计默认，请确认）
- [ ] 维修备件与普通配件：合并 / 分开
- [ ] 单仓库 / 多仓库时间表

### 步骤 3：负库存与拦截策略

为 **销售出库**、**生产领用** 分别选择（可共用同一策略）：

- [ ] 方案 A：允许负库存
- [ ] 方案 B：禁止负库存
- [ ] 方案 C：提醒但不拦截（设计推荐）

### 步骤 4：出入库业务规则

- [ ] 成品入库是否必须关联 BOM/机型成本
- [ ] 是否允许采购入库入整机成品
- [ ] 售后维修是否扣库存（暂不 / 扣减 / 单独领用单）
- [ ] 售后维修件是否纳入库存类型

### 步骤 5：成本与财务边界

- [ ] 成本价先保持现有物料价/机型成本快照
- [ ] 暂不上移动加权平均
- [ ] 暂不改应收、应付、财务核心（设计推荐）

### 步骤 6：填写确认表

在设计文档第 9 节表格中填写「用户确认」列，或另存确认摘要：

建议路径：`docs/worklog/reports/ver29_rc15_006_inventory_design_user_confirmed_yyyyMMdd.md`
