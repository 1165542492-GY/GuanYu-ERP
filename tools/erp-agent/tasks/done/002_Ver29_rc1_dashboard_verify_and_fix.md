# 执行步骤

1. 运行 `dotnet build ERP.csproj`，确认 0 错误 0 警告。
2. 启动开发版 ERP，确认 `http://127.0.0.1:8787` 可访问。
3. 登录后进入首页「老板经营驾驶舱」。
4. 逐项切换统计范围：今日、本月、本年、全部，检查数据刷新与金额显示。
5. 检查经营总览卡片：应收、应付、库存、利润等金额格式与单位。
6. 检查待办预警区域：缺货、超期应收/应付等是否正常展示。
7. 检查排行榜：应收 Top、应付 Top、库存 Top 等列表与标题。
8. 检查快捷入口：点击各入口，确认能跳转到对应业务页面。
9. 切换显示大小：标准、大、超大，检查布局不乱、文字不截断异常。
10. 发现问题时，仅修复首页显示、文案、轻微 JS 渲染问题。
11. 修复后重新 build 并浏览器复验。
12. 输出验收与小修报告。
