## 7. 成本价

暂不上移动加权平均。

# 五、具体开发要求

## 1. 物料模型增加字段

请为物料主数据增加或确认以下字段：

1. StockType / 库存类型
2. IsInventoryItem / 是否纳入库存
3. IsFinishedGood / 是否成品
4. IsServicePart / 是否售后维修件
5. SafetyStock / 安全库存
6. DefaultWarehouse / 默认仓库
7. CostMethod / 成本方式

字段默认值建议：

- StockType：外购配件
- IsInventoryItem：true
- IsFinishedGood：false
- IsServicePart：false
- SafetyStock：0
- DefaultWarehouse：默认仓库
- CostMethod：固定成本价

兼容要求：

旧数据没有这些字段时，读取时自动补默认值，不允许报错。

## 2. 库存类型字典

库存类型下拉固定选项：

- 原材料
- 外购配件
- 标准件
- 成品设备
- 维修备件
- 低值易耗品
- 其他

成本方式下拉固定选项：

- 固定成本价
- 最近采购价
- 机型成本快照
- 手动指定

注意：

本阶段不实现移动加权平均。

## 3. 物料管理页面

在物料管理新增 / 编辑弹窗增加字段：

1. 库存类型
2. 是否纳入库存
3. 是否成品
4. 是否维修备件
5. 安全库存
6. 默认仓库
7. 成本方式

列表中至少展示：

1. 库存类型
2. 是否纳入库存
3. 安全库存
4. 默认仓库

筛选区增加：

1. 库存类型筛选
2. 是否纳入库存筛选

要求：

- 页面不要撑爆
- 保持现有风格
- 保存按钮防重复提交规则保持
- 弹窗点击空白处不关闭规则保持
- 错误提示使用人话
- 不要出现 Error / Bad Request / [object Object]

## 4. 库存汇总页面

库存汇总列表增加显示：

1. 库存类型
2. 是否成品
3. 是否维修备件
4. 安全库存
5. 库存状态

库存状态规则：

- 当前库存数量 <= 0：缺货
- 当前库存数量 > 0 且 当前库存数量 < 安全库存：偏低
- 当前库存数量 >= 安全库存：正常
- 如果 SafetyStock 为空或 0，只要库存数量 > 0 就显示正常

本阶段只做展示和轻量状态判断。

不要重构库存核心计算。

如果库存汇总代码目前按名称汇总，本阶段可以先补显示字段，但不要大改计算逻辑。

如发现必须大改计算才能按 ID / 类型 / 仓库汇总，请先记录为后续阶段，不要硬改。

## 5. 采购 / 销售 / 生产 / 成品入库页面轻量带出

## 6. 采购入库暂不允许整机成品
