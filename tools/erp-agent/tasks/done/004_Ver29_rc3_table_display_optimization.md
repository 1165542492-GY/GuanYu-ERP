# 执行步骤

1. 运行 `dotnet build ERP.csproj`，确认 0 错误 0 警告。
2. 梳理主要业务列表页面：首页、销售、采购、库存、客户、物料、合同等。
3. 为每个列表确定「常用列」与「详情列」，默认表格只显示常用列。
4. 将详细字段移入详情弹窗或展开行。
5. 统一日期显示格式为 `yyyy-MM-dd HH:mm`（前端格式化，不改存储）。
6. 长名称列添加省略号 + `title` 悬停完整显示。
7. 调整列宽与表格布局，减少横向滚动。
8. 用测试数据（含长名称）验证表格不被撑爆。
9. 切换标准/大/超大显示模式，验证布局正常。
10. build 并浏览器逐项复验。
11. 输出优化报告。
