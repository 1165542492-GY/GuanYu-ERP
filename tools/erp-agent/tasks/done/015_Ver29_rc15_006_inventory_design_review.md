# 一、生成 006 / 库存深化设计方案

请生成文件：

docs/worklog/reports/ver29_rc15_006_inventory_design.md

内容必须包括以下章节：

## 1. 当前库存现状

说明：

- 当前已有采购入库、销售出库、生产领用、成品入库、库存汇总等模块
- 当前不能直接改库存核心计算
- 当前不能直接执行 006
- 当前只做设计

## 2. 数控机床小厂库存类型设计

库存类型建议至少包括：

1. 原材料
2. 外购配件
3. 标准件
4. 成品设备
5. 维修备件
6. 低值易耗品
7. 其他

请说明每一种类型适合放哪些东西：

- 钢材、板材、加工件属于原材料
- 电机、丝杆、导轨、电气件属于外购配件
- 螺丝、轴承、密封圈属于标准件
- CK6150、VMC850 等整机属于成品设备
- 售后维修常用件属于维修备件

## 3. 物料主数据需要增加或明确的字段

请设计字段，但不要写代码：

1. StockType / 库存类型
2. IsInventoryItem / 是否纳入库存
3. IsFinishedGood / 是否成品
4. IsServicePart / 是否售后维修件
5. SafetyStock / 安全库存
6. DefaultWarehouse / 默认仓库
7. CostMethod / 成本方式
8. Remark / 备注

说明每个字段用途、默认值、是否必填。

## 4. 库存汇总规则

必须明确后续库存汇总按：

1. 物料 ID
2. 库存类型
3. 仓库
4. 必要时再按批次 / 来源

必须写清楚：

- 同名不同 ID 的物料不能合并
- 同名但库存类型不同的物料不能合并
- 成品和配件不能混在一起
- 维修备件和普通销售配件是否合并，需要用户确认

## 5. 出入库影响规则

请设计后续规则。

采购入库：

- 对原材料、外购配件、标准件、低值易耗品增加库存
- 是否允许成品通过采购入库，需用户确认

销售出库：

- 对成品设备、外购配件、标准件减少库存
- 销售出库是否必须校验库存不足，需用户确认

生产领用：

- 对原材料、外购配件、标准件减少库存
- 是否允许负库存，需用户确认

成品入库：

- 对成品设备增加库存
- 是否必须关联 BOM / 机型成本，需用户确认

售后维修用料：

- 暂不直接接库存代码
- 先设计为“售后维修件领用”候选方案
- 是否纳入库存，需用户确认

## 6. 负库存规则候选

请列出 3 种方案：

方案 A：允许负库存

- 优点：小厂录单不卡流程
- 缺点：库存可能长期不准

方案 B：禁止负库存

- 优点：库存严谨
- 缺点：录单前必须先补入库

方案 C：提醒但不拦截

- 优点：兼顾灵活和提醒
- 缺点：仍可能产生负库存

推荐：

小厂前期建议采用“提醒但不拦截”，等流程稳定后再改成禁止负库存。

## 7. 成本价规则候选

请列出 4 种方案：

1. 固定成本价
2. 最近采购价
3. 移动加权平均
4. 手动指定成本价

推荐：

当前阶段建议先保持“物料成本价 / 机型成本快照”为主，不立即上移动加权平均。

移动加权平均等库存流程稳定后再做。

## 8. 与应收 / 应付 / 财务的边界

必须写清楚：

- 006 / 库存类型深化不应直接修改应收核心计算
- 不应直接修改应付核心计算
- 不应直接修改财务核心计算
- 销售订单生成应收、采购单生成应付先保持现状
- 库存深化只影响库存分类、库存汇总、出入库校验、库存价值展示
- 后续财务联动必须单独开任务

## 9. 需要用户确认的问题清单

请整理为勾选表，至少包括：

- 是否启用库存类型字段？
- 库存类型有哪些？
- 售后维修件是否单独库存类型？
- 是否允许负库存？
- 销售出库库存不足是否拦截？
- 生产领用库存不足是否拦截？
- 成品入库是否必须关联机型成本？
- 成本价是否先保持现有规则？
- 是否暂不做移动加权平均？
- 是否暂不动应收应付财务核心？

## 10. 分阶段开发计划

请拆成阶段：

1. 阶段 1：只增加库存类型字段和页面展示
2. 阶段 2：库存汇总按类型 / ID / 仓库区分
3. 阶段 3：出入库页面带出库存类型
4. 阶段 4：库存不足提醒
5. 阶段 5：售后维修件库存候选
6. 阶段 6：成本价深化
7. 阶段 7：财务联动单独设计

每个阶段都要写：

- 目标
- 涉及页面
- 涉及接口
- 风险
- 验收点
