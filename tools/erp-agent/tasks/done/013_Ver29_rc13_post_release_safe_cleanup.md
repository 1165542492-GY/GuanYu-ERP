# 013_Ver29_rc13_post_release_safe_cleanup

## 任务名称

Ver2.9-rc13：正式 App 运行后安全补漏观察

## 当前基线

- 当前正式 App 已同步到 Ver2.9-rc12
- 当前 Git HEAD：5769a12 Ver2.9-rc12 formal app sync archive
- 当前分支：codex/ver2.8-basic-business-framework
- rc12 人工验收全部通过

## 任务目标

本任务只做正式 App 运行后的安全补漏观察。

重点检查：

1. 首页是否正常
2. 操作记录是否正常
3. 售后维修工单是否正常
4. 测试数据导入导出是否正常
5. 系统设置危险操作提示是否清楚
6. 子账号 / 权限提示是否清楚
7. 页面是否还有 Error / Failed / [object Object] / undefined / null / JSON 糊屏
8. 是否还有原生 alert 小白框残留
9. 是否有明显页面撑爆
10. 是否有明显误导用户的提示

## 明确禁止

本任务禁止：

1. 不同步正式 App
2. 不 tag
3. 不执行 006
4. 不接库存深化
5. 不清空数据
6. 不修改库存核心计算
7. 不修改应收核心计算
8. 不修改应付核心计算
9. 不修改财务核心计算
10. 不删除正式 App / Data / Backups
11. 不恢复备份
12. 不做大规模重构

## 可允许修改范围

如发现问题，只允许低风险修复：

1. 文案
2. 空态提示
3. Toast 提示
4. 弹窗标题
5. 删除确认说明
6. 导入 / 批量结果展示
7. 操作记录展示文案
8. 不影响业务计算的小 UI 问题

## 验收要求

如果无问题：

- 输出“rc13 无需开发，进入观察完成”
- 不改代码

如果有问题：

- 列出问题

- build 0 错 0 警告

- 打包复核日志
- 未经确认不得 commit/push
