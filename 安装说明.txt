冠誉ERP管理系统 Ver1.9
========================

一、安装步骤
1. 解压“冠誉ERP管理系统Ver1.9.zip”到任意文件夹，例如 D:\冠誉ERP
2. 进入解压后的文件夹
3. 右键 GuanYuERP.exe，选择“以管理员身份运行”
4. 程序启动后会出现在 Windows 系统托盘，并自动打开浏览器

二、访问地址
- 本机访问：http://127.0.0.1:8787/
- 局域网访问：使用程序界面中显示的局域网地址
- 同一局域网内其他电脑可共用同一套数据

三、首次登录
- 管理员账号：admin
- 默认密码：admin123
- 正式使用前请规划账号和密码管理方案

四、数据保存位置
程序运行数据默认保存在：
C:\ProgramData\智造ERP供应商管理

该目录包含：
- 供应商、客户、物料、财务等业务 JSON 数据
- backups 备份目录
- operation.log 操作日志

升级、迁移或重装前，请先完整备份上述目录。

五、常见问题
1. 程序无法启动
   请确认是否已“以管理员身份运行”。

2. 局域网其他电脑无法访问
   请检查 Windows 防火墙是否允许端口 8787，并确认访问地址使用的是服务器电脑的局域网 IP。

3. 提示程序已经在运行
   说明系统已在运行，请查看系统托盘图标，或在任务管理器中结束旧进程后再启动。

4. 数据丢失风险
   程序运行期间不要手工编辑 JSON 数据文件；建议定期使用程序内的“立即备份”功能。

六、版本说明
详细功能记录请查看同目录下的 VERSION.md。
