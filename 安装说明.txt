冠誉ERP管理系统 Ver2.6
========================

一、安装步骤
1. 解压“冠誉ERP管理系统Ver2.6.zip”到任意文件夹，例如 D:\冠誉ERP
2. 进入解压后的文件夹
3. 右键 ERP.exe，选择“以管理员身份运行”
4. 程序启动后会出现在 Windows 系统托盘，并自动打开浏览器

二、访问地址
- 本机访问：http://127.0.0.1:8787/
- 局域网访问：使用程序界面中显示的局域网地址
- 同一局域网内其他电脑可共用同一套数据

三、首次登录
- 管理员账号：admin
- 默认密码：admin123
- 首次启动且 users.json 不存在时，系统会自动创建系统管理员账号
- 修改密码后以实际设置为准，重启或升级不会恢复为 admin123
- 子账号由系统管理员在「设置 → 系统设置 → 账号管理」中新增并分配权限

四、数据保存位置
程序运行数据默认保存在：
C:\ProgramData\智造ERP供应商管理

该目录包含：
- 供应商、客户、物料、财务等业务 JSON 数据
- bom.json（BOM表）、model_costs.json（机型成本）、system_settings.json（系统税率）
- contracts.json（合同）、contract_settings.json（合同资料）
- users.json 账号与权限数据（密码 SHA256 哈希存储）
- backups 备份目录
- operation.log 操作日志

升级、迁移或重装前，请先完整备份上述目录。

五、账号说明
- admin 为系统主账号，拥有全部权限，不可删除、不可禁用
- 子账号默认无业务权限，需管理员勾选后才能操作对应模块
- 无权限时菜单隐藏或提示「无权限操作」

六、Ver2.6 新增功能
- 财务收支支持 CSV/XLSX 表格导入、模板下载和逐行错误反馈
- 所有页面顶部统一显示当前账号与权限，超大显示时侧栏菜单可正常滚动点击
- 所有弹窗禁止点击外部空白处或按 ESC 自动关闭
- BOM 与机型成本按物料管理当前价格实时核算，缺价时显示警告
- BOM 已使用的物料禁止删除

七、Ver2.5 新增功能
- 合同管理 → 合同资料：维护合同范本、付款方式、交货/包装/运输、税率、质保条款、收款账户等参数
- 合同管理 → 合同：创建设备购销合同，支持设备明细、随机配件、设备配置表、技术参数表
- 合同金额自动计算（合计、定金、余款、分期），自动生成中文大写金额
- 合同 HTML 预览与打印（浏览器打印 / 另存为 PDF）
- 保存合同时锁定条款与附表快照，后续资料修改不影响旧合同

八、Ver2.4 新增功能
- BOM 表支持导出 CSV、导入 CSV、下载导入模板
- 机型成本支持导出 CSV、导入 CSV、下载导入模板
- 导入时校验数据并显示导入结果（新增/更新/跳过/失败明细）
- BOM 导入保持价格快照逻辑，不会自动读取物料最新价格

八、Ver2.3 功能（保留）
- 生产管理 → BOM表：维护物料清单，保存价格快照，自动计算材料成本
- BOM 编辑时可「重新取最新物料价格」，未手动更新前旧 BOM 不受物料涨价/降价影响
- 生产管理 → 机型成本：当前仅统计 BOM 材料成本（总成本 = 材料成本）
- 设置 → 系统设置 → 税率修改：默认 10%，用于 BOM 含税价换算
- 物料管理新增「价格类型：含税 / 不含税」

九、常见问题
1. 程序无法启动
   请确认是否已“以管理员身份运行”。

2. 局域网其他电脑无法访问
   请检查 Windows 防火墙是否允许端口 8787，并确认访问地址使用的是服务器电脑的局域网 IP。

3. 提示程序已经在运行
   说明系统已在运行，请查看系统托盘图标，或在任务管理器中结束旧进程后再启动。

4. 数据丢失风险
   程序运行期间不要手工编辑 JSON 数据文件；建议定期使用程序内的“立即备份”功能。
