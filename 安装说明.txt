冠誉ERP管理系统 Ver2.7
========================

一、安装步骤
1. 解压“冠誉ERP管理系统Ver2.7.zip”到任意文件夹，例如 D:\冠誉ERP
2. 进入解压后的文件夹
3. 右键 ERP.exe，选择“以管理员身份运行”
4. 程序启动后会出现在 Windows 系统托盘，并自动打开浏览器

二、访问地址
- 本机访问：http://127.0.0.1:8787/
- 局域网访问：使用程序界面中显示的局域网地址
- 同一局域网内其他电脑可共用同一套数据

三、首次登录
- 管理员账号：admin
- 默认密码：admin123
- 首次启动且 users.json 不存在时，系统会自动创建系统管理员账号
- 修改密码后以实际设置为准，重启或升级不会恢复为 admin123
- 子账号由系统管理员在「设置 → 系统设置 → 账号管理」中新增并分配权限

四、数据保存位置
程序运行数据默认保存在：
C:\ProgramData\智造ERP供应商管理

该目录包含：
- 供应商、客户、物料、财务等业务 JSON 数据
- bom.json（BOM表）、model_costs.json（机型成本）、system_settings.json（系统税率）
- dictionary_options.json（字典选项，Ver2.7）
- contracts.json（合同）、contract_settings.json（合同资料）
- users.json 账号与权限数据（密码 SHA256 哈希存储）
- backups 备份目录
- operation.log 操作日志

升级、迁移或重装前，请先完整备份上述目录。

五、账号说明
- admin 为系统主账号，拥有全部权限，不可删除、不可禁用
- 子账号默认无业务权限，需管理员勾选后才能操作对应模块
- 无权限时菜单隐藏或提示「无权限操作」
- 字典选项（Ver2.7）仅 admin 可见、可操作；子账号在系统设置中看不到该入口

六、Ver2.7 新增功能

（1）删除链路保护
引用关系：供应商 → 物料 → BOM → 机型成本
- 供应商被物料引用时，不能删除供应商
- 物料被 BOM 引用时，不能删除物料
- BOM 被机型成本引用时，不能删除 BOM
删除失败时界面会显示后端返回的中文提示信息。

（2）机型成本启用 / 停用
- 列表显示「状态」列（启用 / 停用）
- 操作列可点击「启用」或「停用」切换状态
- 启用状态的记录不能删除，须先停用后再删除
- 导入、导出、模板、列表均包含状态字段
- 材料成本合计与平均成本仅统计启用记录（页面有说明）

（3）BOM 弹窗优化
- 明细表格可横向、纵向滚动，表头固定
- 「保存 BOM」与「新增明细行」在同一栏
- 新增明细行出现在表格顶部
- 物料下拉仅显示启用物料；编辑时已选物料仍显示
- 弹窗顶部显示当前系统税率及成本核算说明
- 不再显示「重新取最新物料价格」按钮

（4）字典选项
路径：设置 → 系统设置 → 字典选项（仅管理员）
- 维护客户分类、供应商分类、物料分类、收支分类、合同分类、订单分类等
- 支持新增、编辑、删除、启用、停用
- 可按分类类型、关键字、状态查询
- 客户/供应商/物料/财务页面的下拉联动将在后续版本逐步接入

七、Ver2.7 建议测试步骤
1. 用 admin 登录，分别测试供应商、物料、BOM、机型成本的删除保护（被引用时应失败并显示中文原因）
2. 在机型成本页面测试启用/停用按钮；启用状态下尝试删除应被拦截
3. 打开 BOM 新增/编辑弹窗，检查滚动、表头、按钮位置与新行位置
4. 进入字典选项，测试增删改与筛选；用子账号登录确认无字典入口
5. 导出/导入机型成本 CSV，确认含「状态」列

十一、常见问题
1. 程序无法启动
   请确认是否已“以管理员身份运行”。

2. 局域网其他电脑无法访问
   请检查 Windows 防火墙是否允许端口 8787，并确认访问地址使用的是服务器电脑的局域网 IP。

3. 提示程序已经在运行
   说明系统已在运行，请查看系统托盘图标，或在任务管理器中结束旧进程后再启动。

4. 数据丢失风险
   程序运行期间不要手工编辑 JSON 数据文件；建议定期使用程序内的“立即备份”功能。

5. 删除提示看不懂
   Ver2.7 起删除失败会直接显示后端中文原因，请根据提示先解除引用或停用记录。
