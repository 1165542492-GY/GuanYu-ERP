冠誉ERP管理系统 Ver2.8-rc3.6.1
================================

Ver2.8-rc3.6 修复 rc3.5 复杂回归问题（稳定测试节点，修复来源于 rc3.6-dev 定点复测）：
1. 自动/关联采购单生成的应付款、自动/关联销售订单生成的应收款禁止直接删除。
2. 有收付款明细或已收/已付金额时，应收/应付删除后端 409 拦截。
3. 删除最后一条收款/付款明细后，已收/已付金额归零并重算状态。
4. 已确认生产领用不能重复确认；库存不足确认 409 拦截。
5. rc3.6 定点复测 10/10 PASS。

Ver2.8-rc3.5 新增「操作影响预检 / 影响范围提示」：删除、确认、编辑、清空、恢复等关键操作前，系统会提前显示影响范围；不能做的操作直接拦截，有风险的操作需二次确认后继续。前后端均会校验，不依赖前端弹窗 alone。

一、安装与启动（Windows 双击版）

【推荐】正式发布后使用：

1. 在源码目录执行 `发布冠誉制造ERP.bat`，生成：
   D:\冠誉制造ERP\App\冠誉制造ERP.exe
2. 主电脑双击 `冠誉制造ERP.exe`（或桌面快捷方式「冠誉制造ERP」）
3. 程序启动后出现在 Windows 系统托盘，并自动打开浏览器
4. 首次运行若提示需要权限，请右键选择「以管理员身份运行」

【开发者】源码编译调试：

1. 进入源码目录，执行 dotnet build
2. 运行 bin\Debug\net8.0-windows\冠誉制造ERP.exe

二、访问地址
- 主电脑本机：http://127.0.0.1:8787/
- 老婆/其他电脑（局域网）：http://主机IP:8787/
  例如：http://192.168.1.28:8787/
- 同一局域网内其他电脑共用主电脑 D 盘数据，不要在多台电脑各自运行 ERP

三、首次登录
- 管理员账号：admin
- 默认密码：admin123
- 首次启动且 users.json 不存在时，系统会自动创建系统管理员账号
- 修改密码后以实际设置为准，重启或升级不会恢复为 admin123
- 子账号由系统管理员在「设置 → 系统设置 → 账号管理」中新增并分配权限

四、数据保存位置
ERP 正式业务数据固定保存在 D 盘：

D:\冠誉制造ERP\Data          ← 业务 JSON 数据
D:\冠誉制造ERP\Backups       ← 自动备份、手动备份
D:\冠誉制造ERP\Exports       ← 建议保存浏览器导出的 CSV/Excel
D:\冠誉制造ERP\Imports       ← 建议放置待导入的 Excel/CSV 文件

Data 目录包含：
- 供应商、客户、物料、财务等业务 JSON 数据
- bom.json（BOM表）、model_costs.json（机型成本）、system_settings.json（系统税率）
- dictionary_options.json（字典选项，Ver2.7）
- sales_orders.json、sales_outbounds.json、purchase_orders.json、purchase_inbounds.json（Ver2.8）
- production_picks.json、finished_inbounds.json、receivables.json、payables.json（Ver2.8）
- contracts.json（合同）、contract_settings.json（合同资料）
- users.json 账号与权限数据（密码 SHA256 哈希存储）
- operation.log 操作日志

Backups 目录包含程序自动备份、手动备份及清空前备份。

旧版数据目录 C:\ProgramData\智造ERP供应商管理 仅作历史兼容，不再作为正式数据目录。
首次启动时，若新目录尚无 JSON 数据且旧目录存在，程序会自动复制旧目录 JSON 到新目录（不删除旧目录、不覆盖新目录已有文件）。

重要提示：
- 不要把 ERP 数据目录放在 WPS 云盘、OneDrive、百度网盘等同步目录中
- 多电脑使用时，只能在一台主机运行 冠誉制造ERP.exe，其他电脑只用浏览器访问，不要多台电脑各自运行一套 ERP

升级、迁移或重装前，请先完整备份 D:\冠誉制造ERP 目录。

五、账号说明
- admin 为系统主账号，拥有全部权限，不可删除、不可禁用
- 子账号默认无业务权限，需管理员勾选后才能操作对应模块
- 无权限时菜单隐藏或提示「无权限操作」
- 字典选项（Ver2.7）仅 admin 可见、可操作；子账号在系统设置中看不到该入口
- Ver2.8 新增销售/采购/库存/应收应付等模块权限，子账号需管理员勾选

六、Ver2.8 新增功能

（1）主业务基础框架
新增并可用的菜单与模块：
- 销售管理：销售订单、销售出库
- 采购管理：采购单、采购入库
- 生产管理：生产领用、成品入库（BOM表、机型成本保留 Ver2.7 功能）
- 仓库管理：库存汇总（只读，不可手工新增库存）
- 财务管理：应收款、应付款（财务收支保留原有功能）

各模块支持新增、编辑、删除、查询。单据编号自动生成。金额保留 2 位小数。删除前需确认。弹窗点击空白处不会关闭。

（2）库存汇总第一版
仅统计「已确认」记录：
当前库存 = 采购入库已确认 + 成品入库已确认 - 销售出库已确认 - 生产领用已确认

（3）预留联动（本版未实现）
销售/采购订单与出入库自动下推、业务单据自动生成应收应付、库存品名与物料档案统一等，将在后续版本完善。

七、Ver2.8 建议测试步骤
1. admin 登录，进入销售订单，新增一条记录，确认金额=数量×单价
2. 分别新增采购入库、成品入库（状态选「已确认」），再新增销售出库、生产领用（已确认）
3. 打开库存汇总，确认数量计算正确；草稿状态记录不应计入
4. 应收款/应付款：输入金额，确认未收/未付自动计算
5. 测试删除确认与弹窗遮罩不可关闭
6. 回归 Ver2.7：删除链路、机型成本启停、BOM 弹窗、字典选项

（4）一键清空测试数据（仅 admin）
路径：设置 → 系统设置 → 数据维护
- 用于测试阶段快速清空业务测试数据
- 默认二次密码：88888888（与登录密码无关，保存在 system_settings.json）
- 清空前自动备份到 backups/backup_before_clear_年月日_时分秒/（完整数据清单，与手动备份一致）
- 须输入二次密码，并准确输入确认文字「确认清空」
- 会清空：客户、供应商、物料、BOM、机型成本、合同、财务、Ver2.8 全部业务 JSON
- 不会清空：账号、权限、系统设置、字典选项、合同资料模板
- 子账号看不到入口，也不能调用接口

（4b）深度初始化空库（仅 admin）
路径：设置 → 系统设置 → 数据维护
- 用于交付前、测试环境重置、准备干净空库
- 会清空：全部业务数据、操作记录（保留一条初始化记录）、备份恢复记录、历史备份文件夹、测试痕迹
- 不会清空：admin、用户、权限、系统设置、二次密码、字典、税率、编号规则、合同模板
- 执行前自动创建最终备份 backup_before_deep_initialize_年月日_时分秒/；备份失败禁止继续
- 须输入二次密码，并准确输入确认文字「我确认深度初始化空库」
- 与普通「清空全部业务数据」的区别：普通清空保留操作记录和历史备份；深度初始化一并清理运行痕迹
- 接口：POST /api/admin/deep-initialize

（5）测试数据导入导出（长期保留，仅 admin）
路径：设置 → 系统设置 → 测试数据导入导出
- 系统长期保留功能，用于测试数据备份、恢复、回归测试
- 仅系统管理员可见入口、可操作；子账号无入口，强行访问提示无权限并返回首页
- 一键导出：ERP测试数据总表yyyyMMdd.xlsx（多 Sheet Excel）
- 支持选择 Excel 总表进行预检查和正式导入
- 库存汇总 Sheet 仅导出参考，不正式导入
- 接口：GET /api/test-data/export-all、POST /api/test-data/import-preview、POST /api/test-data/import-run
- 子账号调用上述接口返回 403
- 不影响各模块原有单页 CSV 导出

九、Ver2.7 新增功能

（1）删除链路保护
引用关系：供应商 → 物料 → BOM → 机型成本
- 供应商被物料引用时，不能删除供应商
- 物料被 BOM 引用时，不能删除物料
- BOM 被机型成本引用时，不能删除 BOM
删除失败时界面会显示后端返回的中文提示信息。

（2）机型成本启用 / 停用
- 列表显示「状态」列（启用 / 停用）
- 操作列可点击「启用」或「停用」切换状态
- 启用状态的记录不能删除，须先停用后再删除
- 导入、导出、模板、列表均包含状态字段
- 材料成本合计与平均成本仅统计启用记录（页面有说明）

（3）BOM 弹窗优化
- 明细表格可横向、纵向滚动，表头固定
- 「保存 BOM」与「新增明细行」在同一栏
- 新增明细行出现在表格顶部
- 物料下拉仅显示启用物料；编辑时已选物料仍显示
- 弹窗顶部显示当前系统税率及成本核算说明
- 不再显示「重新取最新物料价格」按钮

（4）字典选项
路径：设置 → 系统设置 → 字典选项（仅管理员）
- 维护客户分类、供应商分类、物料分类、收支分类、合同分类、订单分类等
- 支持新增、编辑、删除、启用、停用
- 可按分类类型、关键字、状态查询
- 客户/供应商/物料/财务页面的下拉联动将在后续版本逐步接入

十三、常见问题
1. 程序无法启动
   请确认是否已“以管理员身份运行”。

2. 局域网其他电脑无法访问
   请检查 Windows 防火墙是否允许端口 8787，并确认访问地址使用的是服务器电脑的局域网 IP。

3. 提示程序已经在运行
   说明系统已在运行，请查看系统托盘图标，或在任务管理器中结束旧进程后再启动。

4. 数据丢失风险
   程序运行期间不要手工编辑 JSON 数据文件；建议定期使用程序内的“立即备份”功能。

5. 删除提示看不懂
   Ver2.7 起删除失败会直接显示后端中文原因，请根据提示先解除引用或停用记录。
