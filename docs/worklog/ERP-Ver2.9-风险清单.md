# ERP Ver2.9 风险清单

> 自动任务工作台按风险等级控制可自动执行的操作范围。等级越高，越需要人工确认。

---

## R0 只读检查（可自动执行）

| 操作 | 说明 |
|------|------|
| `git status` | 查看工作区状态 |
| `git log` | 查看提交历史 |
| `dotnet build` | 编译检查 |
| GET 接口检查 | HTTP GET 只读接口 |
| 生成报告 | 写入 `docs/worklog/reports/` |

---

## R1 低风险 UI（可自动执行，建议人工抽查）

| 操作 | 说明 |
|------|------|

| 卡片 | 卡片布局与样式 |
| 表格列 | 列显示/隐藏 |
| 日期格式 | 前端日期展示格式 |
| 字体间距 | CSS 样式微调 |

---

## R4 禁止自动执行（脚本内置拦截）

以下操作**绝不允许**出现在自动任务脚本或 Cursor CLI 自动执行中：

| 操作 | 原因 |
|------|------|
| 清空数据 | 不可逆数据丢失 |
| 删除 `D:\冠誉制造ERP\Data` | 正式数据目录 |
| 删除 `D:\冠誉制造ERP\App` | 正式应用目录 |
| 删除 `D:\冠誉制造ERP\Backups` | 备份目录 |
| `git reset` | 可能丢失未提交工作 |
| `git clean` | 可能删除未跟踪文件 |
| `git push --force` | 可能覆盖远程历史 |
| 删除 tag | 版本标记不可恢复 |
| 移动 tag | 版本标记混乱 |
| 同步正式 App | 未经验收不得发布 |
| 恢复备份 | 可能覆盖当前数据 |
| 数据迁移 | 结构变更风险 |
| 深度初始化 | 重置系统状态 |
| `git add` / `git commit` / `git push` | 提交须人工决定 |
| `robocopy` 到 `D:\冠誉制造ERP\App` | 禁止自动同步正式环境 |
