## 3. 回归分级

### P0 — 必须通过（阻断发布）

- 系统启动、`dotnet build` 0 错误 0 警告
- 登录、首页、各核心业务页面可打开
- **删除保护**：单条删除确认、批量删除确认、影响预检弹窗
- **数据不误删**：取消删除后数据仍在
- 数据维护二次密码 + 确认文字
- 权限拦截（无权限不可操作）

### P1 — 重要功能（应通过）

- rc2 表单联动（选单自动带出）
- rc6 下一步按钮（跳转 + sessionStorage 预填，不自动生成单据）
- rc4 生产工单状态流转（待生产/生产中/已完成/已取消）
- 导入导出基本可用
- 子账号权限菜单隐藏
- dual-scroll 超大模式下顶部横向滚动条
- API 401/403 权限拦截正常

### P2 — 体验与格式（可后续修）

- 文案、提示语
- 日期/金额显示格式
- 长名称省略、列宽
- 页面布局微调
