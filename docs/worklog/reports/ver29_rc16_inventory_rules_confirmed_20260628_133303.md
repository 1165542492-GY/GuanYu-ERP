## 已确认规则

1. 启用库存类型字段
2. 库存类型采用：
   - 原材料
   - 外购配件
   - 标准件
   - 成品设备
   - 维修备件
   - 低值易耗品
   - 其他
3. 暂时不要半成品
4. 同名不同 ID 不合并
5. 维修备件和普通配件分开
6. 仓库先按单仓库 / 默认仓库处理
7. 销售出库库存不足：提醒但不拦截
8. 生产领用库存不足：提醒但不拦截
9. 成品入库必须关联 BOM 或机型成本
10. 采购入库暂不允许入整机成品
11. 售后维修暂不扣库存，后面单独做维修领用
12. 成本价先保持现有物料价 / 机型成本快照
13. 暂不上移动加权平均
14. 暂不动应收、应付、财务核心计算
