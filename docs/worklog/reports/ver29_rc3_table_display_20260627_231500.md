| 能力 | 实现 |
|------|------|
| 日期格式化 | `formatDateTime()` → `yyyy-MM-dd HH:mm`，仅前端展示 |

## 各页面列表精简与详情

### App.html — 供应商列表

**默认列：** 编号、名称、联系人、电话、应付款、状态、最后更新、操作人、操作

**详情弹窗（查看）：** 供应商品、单位地址、开户行、银行账号、开户行行号

**首页看板：** 客户/供应商/库存名称列增加省略号

### Business.html — 业务单据（8 模块 + 库存）

**列表列（每模块常用列）：**

| 模块 | 默认列 |
|------|--------|
| 销售订单 | 客户名称、销售类型、产品/物料、数量、含税销售金额、订单日期、状态 |
| 销售出库 | 销售订单号、客户、产品、本次出库数量、出库日期、状态 |
| 采购单 | 供应商、物料、数量、金额、订单日期、状态 |
| 采购入库 | 采购单号、供应商、物料、数量、金额、入库日期、状态 |
| 生产领用 | BOM、物料、数量、领用日期、状态 |
| 成品入库 | 产品、数量、金额、入库日期、状态 |
| 应收/应付 | 来源单号、客户/供应商、金额三项、到期日、状态 |
| 库存 | 类型、编码、名称、数量、库存金额 |

**详情：** 各模块「查看」按钮 → `bizDetailModal` 展示全部字段（含备注、成本、来源冗余字段）

**库存详情：** 规格、单位、仓库、成本价等

**应收应付明细：** 日期统一 `formatDateTime`

### Customer.html

**默认列：** 编号、名称、联系人、电话、应收款、状态、最后更新

**详情：** 地址、开户行、银行账号、行号

### Material.html

**默认列：** 编号、供应商、名称/规格、单价、价格类型、状态、最后更新

**详情：** 基准数量/单位、备注

### Contract.html

**合同资料默认列：** 编号、类型、名称、是否默认、状态、更新时间

**合同资料详情：** 排序、备注、资料内容

**合同默认列：** 编号、名称、客户编号、甲方、签订日期、总金额、状态、更新时间

**合同详情：** 定金、余款
