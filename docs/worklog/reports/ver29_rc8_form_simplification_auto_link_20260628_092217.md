## 1. 本轮优化原则

1. **复杂的事系统做，员工只做选择和确认** — 新增/批量弹窗字段对齐，能下拉的不手填。
2. **能自动生成的，不让人手填** — 单号、版本号、BOM 编号等仍由系统生成。
3. **能从档案/来源单据带出的，不让人重复填** — 供应商、物料、BOM、工单、销售/采购来源联动。
4. **能系统计算的，不让人手算** — 采购金额、入库金额、领用成本、成品入库金额、应收/应付未结余额与状态。
5. **数据安全底线保留** — 删除保护、批量删除确认、影响预检、草稿不参与库存/应收应付、确认后才生效。
6. **业务链路 1234 / 4321 兼容** — 采购单→入库与先入库后补来源均支持；后端 Path B 校验不重复加库存/应付。

## 3. 采购单优化

**位置：** 采购管理 → 采购单 → 新增 / 批量添加

- 员工操作：**选供应商 → 选物料 → 填数量 → 保存**。
- 选物料后自动带出：物料编号、名称、规格、单位、采购单价、价格类型（含税/不含税，如字段存在）。
- **采购金额 = 数量 × 采购单价**，数量/单价变化实时重算。
- 采购编号系统自动生成；状态默认草稿。
- 新增与批量添加字段顺序、联动规则一致。
- 保留导入/导出/批量删除与删除保护。

## 4. 采购入库优化

**路径 A（有采购单）：**

- 来源采购单下拉显示：**单号 + 供应商 + 物料 + 未入库数量**。
- 选择后只读带出：采购单号、供应商、物料、规格、单位、单价、已入库/未入库数量。
- 员工仅填**本次入库数量**；**入库金额 = 数量 × 单价**。

**路径 B（无采购单）：**

- 来源采购单为空或「不关联」。
- 手动选供应商 + 物料，自动带出单位、规格、入库单价。
- `Program.cs` `ResolvePurchaseOrderLink()` 允许空 `PurchaseOrderId`，校验供应商+物料，从物料档案取价。

- 草稿不影响库存；已确认才加库存；不破坏现有库存联动。

## 5. BOM 优化

**位置：** 生产管理 → BOM 表 → 新增

- 界面合并 **机型名称 / 产品名称** 为单一「产品/机型名称」，保存时同步 `ModelName`/`ProductName` 兼容旧数据。
- 展示：**产品/机型编号**、**产品/机型名称**。
- BOM 编号系统自动生成。
- **版本号自动**：首版 V1.0，同产品后续 V1.1、V1.2…；高级可微调。
- 明细选物料后自动带出编号、名称、规格、单位、价格、价格类型、税率；**金额 = 用量 × 单价**；总材料成本自动汇总。
- BOM 被引用后的删除/修改保护未动。
