## 简化业务流程设计原则（005 边界，供后续 rc 遵守）

> 目标：约 10 人小工厂，流程尽量简单、清楚、能落地；不要把生产、销售、维修混成一个复杂流程。

| # | 原则 |
|---|------|
| 1 | **少填字段**：能自动带出的尽量自动带出（销售订单 → 客户/产品/BOM/成本；BOM/机型成本 → 产品/规格/单台成本）。 |
| 2 | **生产工单只管车间生产**：只用于需要车间生产/装配的整机或成品，不承担全部业务。 |
| 3 | **配件/物料/现货**：不走生产工单，直接 **销售订单 → 销售出库 → 应收款**。 |
| 4 | **整机车间生产**：**销售订单 → 生产工单 → 生产领用 / 成品入库 → 销售出库 → 应收款**。 |
| 5 | **上门维修（后续）**：不走生产工单；简化版 **维修工单 → 维修配件出库 → 收费结算 → 应收款**。**005 本轮不实现维修模块**，只写边界说明。 |
| 6 | **不做复杂 MRP / 排产 / 多级工序**。 |
| 7 | **只记关键状态与关键金额**：方便老板看进度、仓库看库存、财务看应收。 |
| 8 | **页面提示用通俗语言**：让不懂 ERP 的工人知道下一步点哪里。 |
| 9 | **005 范围**：生产工单基础登记 + 状态流转；不执行 006、不自动扣库存、不自动生成领用/入库。 |
| 10 | **模块分离**：销售出库、生产领用、成品入库、应收各自办理；详情页仅提供跳转入口，不自动联动。 |

## 页面说明（工人可见）

生产工单页顶部四条提示：

1. **适用说明**：只用于车间生产/装配；配件/现货不要建生产工单。
2. **车间生产流程**：销售订单 → 生产工单 → 领用/入库 → 销售出库 → 应收；本页不自动扣库存、不自动生成单据。
3. **上门维修边界**：后续单独做维修工单（005 不实现）。
4. **本页怎么操作**：新增 → 开始生产 → 登记完工；领料/入库去左侧菜单单独做。

表单与列表：

- 客户：下拉选择（编号 / 名称）；销售订单来源时自动锁定；手工来源必选客户。
- 销售订单：下拉标注 `【成品·需生产】` / `【物料·配件】`，选物料类时前端提示一般不需建工单。
- 按钮：**查看详情**、**登记完工**、**取消工单**（与弹窗「取消」按钮 id 分离，避免冲突）。
- 详情：**前往生产领用** / **前往成品入库**（仅跳转）。

## 后端变更

- 模型新增 `CustomerId`，与 `CustomerName` 并存。
- `ResolveProductionWorkOrderCustomer()`：按 Id 或名称匹配客户档案；销售订单来源优先用订单客户。
- **旧 JSON 兼容**：历史工单仅有 `CustomerName` 时仍可显示；编辑保存时提示重新选择客户以写入 `CustomerId`。
